# めざせ！おかいもの名人～だがしやマスター～ PWA

遊びながら計算力がつくお買い物ゲームアプリです。

## ファイル構成

```
dagashi-pwa/
├── index.html      ← アプリ本体（HTML + CSS + JS 全部入り）
├── manifest.json   ← PWA設定（アプリ名・横向き・アイコン）
├── sw.js           ← Service Worker（オフラインキャッシュ）
└── icons/
    ├── icon-192.png  ← ホーム画面用アイコン
    └── icon-512.png  ← スプラッシュスクリーン用
```

## ローカルで動かす

ファイルを直接ブラウザで開いてもゲーム自体は遊べますが、
Service Worker（オフライン対応）を有効にするにはHTTPサーバーが必要です。

```bash
# Python 3 が入っていれば
cd dagashi-pwa
python3 -m http.server 8080

# → ブラウザで http://localhost:8080 を開く
```

## 公開する（GitHub Pages を使う方法）

1. GitHub でリポジトリを作成（例: `dagashi-app`）
2. `dagashi-pwa/` の中身をリポジトリにプッシュ
3. Settings → Pages → Source を `main` ブランチに設定
4. 数分後に `https://あなたのユーザー名.github.io/dagashi-app/` で公開される

これだけでスマホから遊べて、「ホーム画面に追加」もできるようになります。

## スマホでの「ホーム画面に追加」方法

### iPhone (Safari)
1. 上のURLを Safari で開く
2. 共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択
4. 次からホーム画面のアイコンからアプリとして起動

### Android (Chrome)
1. URLを Chrome で開く
2. 「ホーム画面に追加」のバナーが自動表示される
3. または メニュー → 「ホーム画面に追加」

## v1.0 の機能

- 駄菓子屋の商品を選んでカゴに入れる
- お財布から硬貨をタップしてお支払いトレイに置く
- リアルタイムで合計金額が更新される
- ぴったり支払いで特別演出＋ボーナス
- おばあちゃんがヒントをくれる
- レベルシステム（Lv.1〜5、予算が段階的に増加）
- 効果音（チャリン音、成功音）
- 学習進捗のローカル保存（localStorage）
- オフライン対応（Service Worker）
